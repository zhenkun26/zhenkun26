## 🚀 代表项目 Featured Projects

### 🐱 DeskPet · 胡桃桌宠

> “本堂主今天也要元气满满哦！”

一个 Electron 桌面宠物陪伴应用：以胡桃为形象的透明置顶桌宠，支持拖拽互动、AI 角色扮演对话、休息提醒与番茄钟。

- 🎨 Electron 39 + TypeScript 5.7 + electron-vite 三端构建
- 💬 DeepSeek 驱动的 AI 角色对话（SSE 流式输出 + 会话历史）
- ⏰ 休息提醒 + 番茄钟，专治久坐打工人

[📦 查看仓库](https://github.com/zhenkun26/DeskPet) · [MIT License](https://github.com/zhenkun26/DeskPet/blob/main/LICENSE)

### 🤖 BusinessAgent · 企业知识工作流 Agent

> “让打工人只说人话，剩下交给小A。”

一个企业级多 Agent 系统：员工用自然语言完成**知识问答 · 数据分析 · 业务执行**，自带权限隔离、审批闭环与全栈降级。

- 📚 知识问答：RAG 两阶段检索（Milvus 粗排 + BGE 精排）+ 三级降级链
- 📊 数据分析：LLM 规划 + Python 真实聚合，数字坚决不编造
- ⚙️ 业务执行：RBAC 双闸 + 审批闭环 + Saga 补偿
- 🛡️ FastAPI + LangGraph + Milvus + PostgreSQL + Redis + Docker / K8s

[📦 查看仓库](https://github.com/zhenkun26/BusinessAgent)
